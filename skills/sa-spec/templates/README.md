# Локальные снимки шаблонов SA

Канон — страницы Confluence. Эти файлы — **снимок на дату выгрузки**, не замена живого шаблона.

## Как выбирать источник

1. Выгрузить актуальную страницу: `dump_confluence_page.py PAGE_ID`.
2. Если выгрузка не удалась (сеть, 401, таймаут) — взять файл из этой папки.
3. В `context.md` написать: шаблон из Confluence (версия N) **или** локальный снимок (дата, версия в шапке файла).
4. Не вспоминать структуру «как обычно», если нет ни живой страницы, ни снимка.

Обновить снимки:

```bash
python3 ~/.cursor/skills/sa-spec/scripts/refresh_templates.py
```

Список шаблонов в Confluence почти целиком из макросов — для генерации брать конкретный тип, не `list.txt`.

Страницы «создать из шаблона» — это **space-шаблоны** (`/rest/experimental/template/{id}`), не обычные страницы. Публикация создаёт страницу из них, затем заполняет секции. Карта: `sa-publish/space-templates.json`.
