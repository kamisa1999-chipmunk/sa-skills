# Redline существующих страниц

`предложить правку` и `принять правку` — разные шаги. На генерации только предложение.

Машина не удаляет и не переписывает молча существующий текст Confluence.

## Маркеры в Markdown

Новый фрагмент:

```text
{+новый текст+}
```

Фрагмент, который предлагается убрать:

```text
{-старый текст-}
```

Замена — старый красный зачёркнутый, новый зелёный рядом:

```text
{-старый абзац-} {+новый абзац+}
```

`sa-publish` на фазе `draft` рисует `{+ +}` зелёным, `{- -}` красным и зачёркнутым. На фазе `finalize` красное удаляется, зелёное становится обычным текстом. До явного finalize маркеры не снимать.

## Типы правки в `artifact-plan.md`

- `add` — новый фрагмент, старое не трогать;
- `deprecate` — старый текст остаётся и помечается устаревшим;
- `replace` — старый фрагмент в `{- -}`, новая версия рядом в `{+ +}`;
- `link` — только ссылка, остальной документ не переписывать;
- `no-change` — документ проверен, правок нет.

Неизменённые абзацы в черновик заново не копировать и не переписывать. Меняется блок — в redline только этот блок.

## Новая страница

Страницы ещё нет: корпоративный шаблон этого типа, содержимое, в начале строка

```text
> **Generated draft / Сгенерированный черновик**
```

Пока маркер на месте, страница не финальная. Снимает его только finalize после чтения, ревью и явного утверждения.
